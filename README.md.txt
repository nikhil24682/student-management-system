# 🎓 Student Management System

A full-stack Student Management System developed using Spring Boot.

## 🚀 Features

- User Login using Spring Security
- Add Student
- Update Student
- Delete Student
- Search Students
- Pagination
- Form Validation
- Dashboard Statistics
- Exception Handling
- REST APIs

## 🛠️ Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- Thymeleaf
- MySQL
- Bootstrap
- Maven
- Git
- GitHub
